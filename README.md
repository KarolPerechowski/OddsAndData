# Live Football World Cup Scoreboard

A small Java library that tracks in-progress World Cup matches: start a match, update the score, finish a match, and return a ranked summary of games still in progress.

This repository is submitted as it would be for an internal code review. How AI tools were used is documented in [AI.md](AI.md).
